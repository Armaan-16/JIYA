# TASK OBSERVER Reference: Continuous System Evolution

> *"Without observation and reflection, repeating the same mistake is guaranteed."*

---

## The 4 Stages of Agent Evolution

1. **Detection:** Catch friction as it happens (e.g. command timeout, unhandled parameter, user correction).
2. **Externalization:** Log the concrete event with structured context into `skill-observations/observation-log/`.
3. **Pattern Recognition:** Cluster historical observations to uncover systemic skill or rule gaps.
4. **Codification:** Convert lessons into permanent rules, updated invariants, or new skills so the mistake is never repeated.
