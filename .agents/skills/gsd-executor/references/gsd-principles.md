# GSD Principles: High-Velocity Engineering & Pragmatism

> *"Real artists ship."* — Steve Jobs

---

## The Philosophy of Getting Shit Done

1. **Velocity is a Quality Metric:**
   - Delaying execution through endless hypothetical debate creates stagnation.
   - Once security, architecture, and simplicity boundaries are established, move aggressively.

2. **Working Software is the Primary Measure of Progress:**
   - Speculative architecture diagrams and lengthy markdown plans are worthless without running, tested software.

3. **Incremental Progress Beats Grand Visions:**
   - Ship small, verifiable improvements that continuously compound.
   - Each wave must leave the repository in a deployable, working state.
