# CODERABBIT Rule: PR Walkthrough & Summary

> **Mandate:** Help humans and peer agents understand complex diffs in under 60 seconds through structured summaries and sequence flows.

---

## Required Structure of a Review Walkthrough

1. **Executive Summary:**
   - 2–3 sentences summarizing the intent and outcome of the change.
2. **Key Changes by Subsystem:**
   - Bullet points grouped by directory or subsystem (`CORE`, `SERVICES`, `UI`).
3. **Sequence or Data Flow Diagram:**
   - Mermaid diagram illustrating how inputs flow through new or modified components.
4. **Impact Assessment & Verification Proof:**
   - Blast radius report and automated test results.
